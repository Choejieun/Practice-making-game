# 무명신의 기록

한 인간을 0세부터 관찰하고 개입하는 다크 판타지 싱글플레이 카드 게임 프로토타입입니다.

## 실행

`dist/index.html`을 웹 브라우저로 열면 바로 플레이할 수 있습니다. 설치나 빌드는 필요하지 않습니다.

## 한 판의 흐름

1. 타이틀에서 게임을 시작하면 신의 독백과 요람 속 아이의 탄생 장면이 이어집니다.
2. 0세에 무작위 성격 키워드 3개를 확인하고, 한 번만 운명을 다시 엮을 수 있습니다.
3. `이 운명을 지켜본다`를 선택하면 본게임 UI가 열립니다.
4. 매 생애 턴마다 진행 카드 후보 3개 중 하나를 선택합니다.
5. 공개 신탁을 즉시 사용하거나 지켜보기를 선택해 활성 시련을 판정합니다.
6. 관계, 아이템, 의지와 과거 사건으로 합성 진행을 해금합니다.
7. 신성 개입이 높아지면 재앙 특수 턴과 인생의 갈림길이 시작됩니다.
8. 죽음, 신 연결 단절, 자연사 또는 관찰 종료 시 생애 회상을 확인합니다.

새 게임마다 성별과 생애 단계별 영웅 초상, 성격, 카드 후보, 시련과 신탁 패가 달라집니다. 상단 생애 궤도에서 유년기부터 노년기까지 현재 위치를 확인할 수 있습니다. 본게임에서는 중앙 진행 화면만 항상 표시되며, 영웅 정보와 생애 기록은 좌우 손잡이에 마우스를 올리거나 클릭해 오버레이로 열 수 있습니다.

전체 UI는 신비로운 남색과 금색을 중심으로 구성했으며, 최소 글자 크기는 10pt입니다. 관계, 기록, 시련, 재앙, 중요 사건, 체력, 특수 아이템 등에는 게임 전용 아이콘을 배치했습니다.

## 서체

국립박물관문화재단이 배포하는 `국립박물관문화재단클래식` Light, Medium, Bold 원본 서체를 사용합니다.
서체 파일은 수정하지 않았으며, 서체 단독 판매 용도로 사용할 수 없습니다.

- 배포처: https://www.nmf.or.kr/agency/sub/20181024100034469100_contents.do

## Render 배포

정적 사이트의 공개 폴더는 `dist`입니다. 저장소에 서체 파일이 없는 배포 환경에서는 다음 빌드 명령으로 공식 배포본을 준비할 수 있습니다.

`bash scripts/prepare-fonts.sh`
